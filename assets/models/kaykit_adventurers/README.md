# KayKit Adventurers (CC0)

Personajes y armas de muestra para el juego 3D, de **Kay Lousberg** (www.kaylousberg.com), licencia **CC0**
(libres para uso comercial, sin atribución obligatoria; ver `LICENSE.txt`).
Fuente: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0

Son de referencia para montar los sistemas (esqueleto, animaciones, equipo) mientras se crea el arte propio.
Usan una sola textura de paleta por personaje: la misma técnica recomendada para los modelos propios.
