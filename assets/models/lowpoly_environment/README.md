# LowPoly Environment Pack

"LowPoly Environment Pack": pack de entorno (árboles, rocas, arbustos, plantas, hierba, troncos, montañas y terrenos) aportado por el dueño
del proyecto. Colores planos, sin texturas. Se importa con `../pixel_look_import.gd` como todos los modelos.
Los objetos sólidos del mundo (árboles, rocas, troncos) tienen su escena con colisión en `src/world/props/`.
